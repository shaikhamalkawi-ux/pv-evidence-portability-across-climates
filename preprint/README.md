# Journal-neutral working manuscript — R19

This directory contains the research **working manuscript** and its accompanying supplement in **journal-neutral, non-MDPI typography**. These are author-review drafts, not peer-reviewed or accepted publications. No journal article DOI has been assigned. The MDPI class, publisher logos, template compilation and submission-only files are intentionally **not** posted here.

- `Manuscript_R19_JournalNeutral_WORKING_DRAFT.pdf`: full main research manuscript (24 A4 pages).
- `Supplement_R19_JournalNeutral_WORKING_DRAFT.pdf`: complete supplementary methods and results (14 A4 pages).
- `JournalNeutral_R19_Source.zip`: LaTeX and figures needed to rebuild these neutral PDFs without the MDPI class.

**Science status:** R19 is an editorial, reproducibility-link, and *display-only figure* improvement relative to the verified R18/R16 science baseline. All underlying pairwise stopping records, response matrices, equations, numerical result tables and 39 bibliography entries are unchanged.

The exact historical-order R18 analysis is separately published in [`reproducibility/R18`](../reproducibility/R18). The figure replot is in [`figures/R19`](../figures/R19). The analysis snapshot is pinned at commit [`cb42962c`](https://github.com/shaikhamalkawi-ux/pv-evidence-portability-across-climates/tree/cb42962c6544a5f9afb4e69d39682799cf932370).
