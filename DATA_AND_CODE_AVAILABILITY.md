# Reviewer access and scope

This is a publicly viewable *derived-result/code companion* for the Global Solar Project 66 manuscript (identified OJIM author candidate dated 18 October 2026). The executable `verify_derived_only.sh` reconstructs the archived independent Stage-A output assertions, and `stageB_derived_audit/reproduce/verify_shortlists.py` reproduces the Stage-B published table example. The larger frozen experimental archive is not publicly redistributed because it includes upstream archival/source material requiring separate rights review. Raw producer files can be obtained directly from the DOIs listed in THIRD_PARTY_DATA.md.

The full retrospective replay also depends on the specified original source archive with SHA256 cca1db15a2b76011401099aa128e47d87552093d94248d6a4d5c35e16ff06d1b and official raw field files; no promise of a one-click clean re-run from raw third-party data is made. Never cite this project repository as if it were the source of producer measurements.
